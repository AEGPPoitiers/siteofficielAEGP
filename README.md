# Site Officiel AEGP
Site officiel de l'AEGP (Association des Étudiant.e.s en Génie Physiologique) de l'Université de Poitiers

## Stack
- **Frontend** : React + Vite ('frontend/')
- **Backend** : Python + FastAPI ('backend/')
- **BDD / Auth** : Supabase (PostgreSQL)
- **Stockage docs** : Cloudflare R2
- **Hébergement** : Vercel(front) + Render(back)

## Structure du repo


  ├── frontend/    # React + Vite

  ├── backend/     # FastAPI
  
  └── docs/        # specs, schémas, guide d'installation

## Démarrage

Voir 'docs/setup-outils.pdf' pour installer les outils nécéssaires.

Ensuite, README spécifiques : 
- 'frontend/README.md'
- 'backend/README.md'

## Contribution

- Branche 'main' protégée -> toujours passer par un PR
- Convention de commits : [Conventionnal Commits](https://www.conventionalcommits.org/fr/v1.0.0/)
- Branches : 'features/...', 'fix/...', 'chore/...', 'docs/...'
